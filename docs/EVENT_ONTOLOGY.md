# Event ontology 1.0.0

The stable MVP labels are `touch`, `controlled_possession`, `intentional_pass`, `clearance`, `interception`, `recovery`, `tackle`, `duel`, `shot`, and `unknown`.

`unknown` is an abstention, not an error bucket. `intentional_pass` requires visible evidence of an attempted teammate-directed action; a possession transition alone is insufficient. Geometry-derived legacy `pass` records are candidate generators only.
